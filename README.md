Prerequisites：
1. A web browser on your desktop.
2. A valid, logged‑in GitHub account.
3. Stable network connection.

Steps：
1. On the GitHub homepage, locate and click the green button labelled “New” to start repository creation.
2. Fill in a distinct repository name in the corresponding input box. You may also add a short description optionally.
3. In the visibility section, select the option “Private”.
4. Tick the checkbox for “Add a README file”.
5. Confirm all settings, then click the “Create repository” button.

Result Check：
1. Open the newly created repository page.
2. Verify that the repository status shows “Private”, and the content of the README file is visible on the main page.
3. If both conditions are satisfied, the task is completed successfully.
